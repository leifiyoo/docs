## Command list

| Command | Description | Permission |
|---|---|---|
| /lpx menu | Opens the rank manager GUI | lockiprefixes.menu |
| /lpx reload | Reloads plugin configuration | lockiprefixes.reload |

## Typical admin flow

1. Run /lpx menu
2. Create or edit ranks
3. Test with a player account
4. Run /lpx reload only if you edited files manually
